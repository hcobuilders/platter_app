  2. 2Opening shows recents before commands. The registry is the source — {id, label, keywords, scope, run()} — so context menus and shortcuts stay in sync automatically.

  2. 5400ms timeout, then say so. Grapefruit border, plain words, no spinner. The roadmap asked for a short budget and a tooltip; this is that, inline.
  3. 6iPad sheet reads the same registry. Building the registry first is what makes this a 40-line component instead of a second implementation.

What Batch 2 commits us to. The card band is glyphs with hover labels, which means every tool in the app needs a glyph in the same drawing style — worth commissioning as one set rather than accumulating. The footer's source label creates an ordering (deep parse → budget table → leveled → contract value) that the budget tool in Batch 5 has to actually produce. And the command registry is now load-bearing for three surfaces: the bar, the iPad sheet, and right-click menus.
